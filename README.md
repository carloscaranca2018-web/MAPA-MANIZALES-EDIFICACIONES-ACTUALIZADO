# Centro de Comando MEMAZ

Versión optimizada para GitHub Pages.

## Ajustes incluidos
- Paleta azul institucional aplicada a encabezado, controles, tarjetas y paneles.
- Tarjetas del Resumen ejecutivo conectadas al filtro y al mapa.
- Botón Ocultar/Mostrar para el Resumen ejecutivo.
- Indicadores de Prioridad crítica y Habitables también filtran el mapa.
- Barra inferior desplazable en móvil con acceso a todos los botones.
- Panel móvil con fondo de cierre, filtros a una columna y diseño adaptable.
- Se conservan consolidación de barrios, normalización de usos, mapa de calor, GPS y exportaciones.

## Publicación
Suba `index.html`, `README.md` y `.gitignore` a la raíz del repositorio. Active GitHub Pages desde la rama principal y la carpeta raíz.
